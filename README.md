# 🐌 Caracol

Aplicación web con temática de apuestas en carreras de caracoles.

- **Autenticación local:** registro, inicio y cierre de sesión con persistencia en LocalStorage.
- **Dashboard:** saldo del usuario, gráfica de apuestas ganadas/perdidas y victorias de los caracoles del día (datos simulados).
- **SnailPay:** pasarela de pagos simulada en Express para recargar saldo, con escenarios de éxito, rechazo y error del sistema.

**Stack:** React · Express · TypeScript · LocalStorage
